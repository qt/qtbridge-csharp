# Release Status

Implementation notes for this page:

## Scope boundary

Owns:

* Beta/pre-release expectations, volatility, and compatibility guidance.
* Licensing, terms, and dependency notes that need more detail than the Introduction page.
* What early adopters should expect while APIs, workflows, packaging, and docs mature.

Does not own:

* General product positioning or first-time conceptual explanation.
* Setup instructions, project templates, or API usage details.
* Detailed changelog-style release history unless that becomes a dedicated section later.

## Content ideas

* Keep this page short and factual.
* Explain that Qt Bridge for C# is currently in beta/pre-release state.
* Explain that APIs, workflows, packaging, and docs may evolve.
* Explain what early adopters should expect:

  * Focused but incomplete documentation.
  * Feedback-driven changes.
  * Some workflows may become smoother over time.
* Include terms/licensing pointers without duplicating the Introduction page too heavily.
* Keep this page out of the main onboarding flow where possible.
