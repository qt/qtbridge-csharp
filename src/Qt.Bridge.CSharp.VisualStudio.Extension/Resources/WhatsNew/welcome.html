Visual Studio Extension

Qt Bridge for C# is ready in Visual Studio

Qt Bridge for C# lets .NET developers keep application logic in familiar C# while QML describes the user interface rendered by Qt Quick.

The Visual Studio extension adds project and item templates, and it can provide QML diagnostics, completion, semantic editor support, and project-aware imports. Basic QML syntax highlighting and completion are available as soon as you open a .qml file. Full bridge-aware support becomes available after the first successful build.

Setup status

✓ Project and item templates Create a new Qt Bridge project or add QML files from Visual Studio. Ready
✓ Basic QML editing support Syntax highlighting and completion for QML and Qt Quick types work as soon as you open a QML file. Ready
✓ Bridge-aware QML support Diagnostics, completion, semantic support, and project-aware imports for your C# types appear after the first successful build. After first build
✓ Output and logging hooks Use the Qt Bridge for C# output pane and optional logging when you need to investigate language-server issues. Available

How it fits together

A Qt Bridge for C# application has two main sides: QML describes the interface that Qt Quick renders, while C# holds your application logic, state, models, bridge attributes, and resources.

C# Application logic, models, and resources.
→
Qt Bridge for C# Exposes selected C# types and metadata to QML.
→
QML Declarative user interface layer.
→
Qt Quick Renders the interface and runs the UI behavior.

C# and QML in one project

Main.qml

import QtQuick
import QtQuick.Controls

ApplicationWindow {
    visible: true

    Counter {
        id: counter
    }

    Column {
        anchors.centerIn: parent
        spacing: 12

        Text {
            text: "Value: " + counter.value
        }

        Button {
            text: "Increment"
            onClicked: counter.increment()
        }
    }
}

Counter.cs

public class Counter : INotifyPropertyChanged
{
    public event PropertyChangedEventHandler? PropertyChanged;

    private int _value;
    public int Value
    {
        get => _value;
        set
        {
            if (_value == value) return;
            _value = value;
            PropertyChanged?.Invoke(
                this, new PropertyChangedEventArgs(nameof(Value)));
        }
    }

    public void Increment() => Value++;
}
  • QML sees C# member names in camelCase, so Value becomes value.
  • INotifyPropertyChanged keeps QML bindings live when your C# state changes.
  • The template sample code uses the same end-to-end idea so you can inspect it immediately after project creation.
