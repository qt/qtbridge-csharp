Qt Bridge for C# is installed

Qt Bridge for C# lets you build C# applications with QML-based Qt user interfaces in Visual Studio. QML is Qt’s declarative UI language, roughly comparable to XAML, but rendered by Qt Quick. Your application logic stays in familiar C# while QML describes the user interface.

How it works

MainWindow.qml — the UI layer

ApplicationWindow {
    ...

    Counter {
        id: counter
    }

    Column {
        ...

        Button {
            text: "Clicks: " + counter.count
            onClicked: counter.increment()
        }

        Button {
            text: "×2"
            onClicked: counter.transform(
                function(value) {
                    return value * 2
                })
        }
    }
}

Counter.cs — the logic layer

public delegate int CounterTransform(int value);

public class Counter : INotifyPropertyChanged
{
    public event PropertyChangedEventHandler PropertyChanged;

    private int _count;
    public int Count
    {
        get => _count;
        private set => { ... }
    }

    public void Increment() => Count++;

    public void Transform(CounterTransform transform)
        => Count = transform?.Invoke(Count) ?? Count;
}
  • Names are lowercased in QML (Count → count).
  • INotifyPropertyChanged keeps the text binding live.
  • Public C# types and members are exposed to QML automatically.
  • JavaScript functions passed from QML map to C# delegates automatically — no marshaling needed. See the C# API documentation for details.
